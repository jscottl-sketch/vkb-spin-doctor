Here’s the Python function that takes a list of numbers and returns the three largest, including error handling and a docstring:

```python
def get_three_largest(numbers):
    """
    Returns the three largest numbers from a list of numbers.

    Args:
        numbers (list): A list of numbers (integers or floats).

    Returns:
        list: A list containing the three largest numbers in descending order.

    Raises:
        ValueError: If the input list has fewer than three numbers.
        TypeError: If the input is not a list or contains non-numeric values.
    """
    # Check if input is a list
    if not isinstance(numbers, list):
        raise TypeError("Input must be a list.")

    # Check if list has at least three numbers
    if len(numbers) < 3:
        raise ValueError("List must contain at least three numbers.")

    # Check if all elements are numeric
    for num in numbers:
        if not isinstance(num, (int, float)):
            raise TypeError("All elements in the list must be numbers.")

    # Sort the list in descending order and return the first three
    sorted_numbers = sorted(numbers, reverse=True)
    return sorted_numbers[:3]

# Example usage:
try:
    result = get_three_largest([5, 2, 8, 1, 9, 3])
    print(result)  # Output: [9, 8, 5]
except (ValueError, TypeError) as e:
    print(f"Error: {e}")
```

### Explanation:
1. **Docstring**: The function includes a clear docstring explaining its purpose, arguments, return value, and possible exceptions.
2. **Error Handling**:
   - Checks if the input is a list (`TypeError` if not).
   - Checks if the list has at least three numbers (`ValueError` if not).
   - Checks if all elements are numeric (`TypeError` if non-numeric values are found).
3. **Functionality**: The function sorts the list in descending order and returns the first three elements.
4. **Example Usage**: Demonstrates how to call the function and handle potential errors.

This implementation ensures robustness and clarity.
