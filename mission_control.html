Plain-English guide to every tab and button. Click a section to expand it.
🏠 Home Tab
What it is: The overview screen. Shows all system areas in cards. Refreshes every 30 seconds automatically.

🏥 Run Health CheckRuns provider_health.py in background. Takes ~30s. Refreshes the health gauge after.
🔭 Start ScoutStarts a recurring web-research run for the default VKB goal. Runs every 30 min.
🔄 Run AAFL GoalPrompts you to type a goal, then queues it in goal_queue.txt for the AI to process.
💾 Save WCCSSame as Save Session Now on the WCCS tab. Saves STATUS.md right now.
Provider Health gaugeCircle shows % of green AI providers. Click Show Details to see each one.
AAFL Score gaugeLast AI run score out of 10. Green=good, red=needs attention.
Costs chartResponse-time bars for active providers. Fastest provider = shortest bar.
Scout Activity sparkline7-day line showing scout activity. Flat = not running.
ALP Savings barHow many savings you have logged vs a target of 30.
System Status lightsGreen=OK, yellow=uncertain, red=problem. MCC Server / AAFL Engine / Scout.
Refresh CardsForce-reload all home cards from server.

📋 Copy HISTORY.mdCopies full HISTORY.md text to your clipboard.

What it is: The main save button lives here. Every save backs up STATUS.md and logs what happened.

📡 How Updates Work (Data Flow)
Saving a session:
1. Paste chat notes into WCCS tab textarea
2. Click Save Session Now
3. Server writes your notes to chat_latest.txt
4. Server runs aafl_wccs.py → updates STATUS.md + HISTORY.md
5. Server copies STATUS.md → archive_dead/STATUS_timestamp.md
6. MCC shows PASS + flashing reminder banner
7. Click "Copy STATUS.md for Claude" button
8. Go to Claude.ai → Project Files → delete old STATUS.md → click + → paste new one

Auto-WCCS:
Toggle ON in the header → server fires every N minutes automatically → same save process, no action needed from you.

What auto-populates:
• Server status dot (every 10s) · Home cards and instruments (every 30s) · Auto-WCCS countdown (1s tick) · ACCA codes (from ACCA.md file) · ALP count · MOT score (after you run it)

What needs manual action:
• Pasting chat summary before save · Clicking Save Session Now · Clicking Copy STATUS.md after save · Uploading STATUS.md to Claude Project Files · Adding new ACCA codes to ACCA.md directly · Adding ALP entries · Running Full MOT

ACCA codes:
Codes are read from ACCA.md as a pipe-table. To add a new code, edit ACCA.md directly and add a row: | CODE | meaning | date |. They appear here on next Refresh.
