AREA 4 — LLOW CANVAS
🔀 LLOW — Loop Law Organiser Window
OCB-D through OCB-H Visual workflow builder inside the AAFL Control tab.

How to use:
1. Drag an element from the left palette onto the canvas
2. Click the output port (right side) of one element, then the input port (left side) of another to connect
3. Drag a CONNECTOR from the palette before connecting to set the arrow type
4. Click ▶ Run Loop to execute the workflow

Palette elements35+ elements: inputs, modes, modifiers, cycle controls, quality checks, outputs, approval gates, endings, junctions.
CONNECTORSOCB-G 15 arrow types: Continue, Jump Back, Branch, Trigger, Repeat, ALP Gate, Timer, Scheduled, etc. Each has a unique line style.
Junction BoxesOCB-G 8 special nodes: Decision (diamond), Merge (trapezoid), Split, Gate, Counter, Logger, Router, Delay. Double-click Gate/Counter/Router/Delay to set parameters.
Preset LoadOCB-G 11 ready-made workflows: Tutorial, Bug Hunt, ALP Audit, Scout Deep Dive, Morning Report, Meta Improve, New Project Bootstrap, Star Citizen Benchmark, and 3 original starters.
Strategy 1: Phase FlowDivides canvas into INPUT/PROCESS/OUTPUT colour bands with zone labels at top.
Strategy 2: Element MirrorCanvas columns wash with each category's colour. Helps spot which category dominates.
Strategy 3: Snap GlowZone pulse-glows when you drag a matching element — guides correct placement.
Snap ModeOCB-H (was Strict Mode). Wrong zone = canvas shake + red flash + snap back. Requires Phase Flow ON.
Ghost bug fixOCB-H Only the grabbed element ghosts while moving. All other elements stay solid.
MinimapSmall overview panel at bottom-right of canvas. Shows all elements at 5% scale.
Execution LogShows each step as it runs. Green=pass, blue=running, red=fail.
Export CLACRConverts workflow into a ready-to-paste CLAC request block for Claude Code.
