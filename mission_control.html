MCC Instructions
Plain-English guide to every tab and button. Click a section to expand it.
🏠 Home Tab
What it is: The overview screen. Shows all system areas in cards. Refreshes every 30 seconds automatically.

🏥 Run Health CheckRuns provider_health.py in background. Takes ~30s. Refreshes the health gauge after.
🔭 Start ScoutStarts a recurring web-research run for the default VKB goal. Runs every 30 min.
🔄 Run AAFL GoalPrompts you to type a goal, then queues it in goal_queue.txt for the AI to process.
💾 Save WCCSSame as Save Session Now on the WCCS tab. Saves STATUS.md right now.
Provider Health gaugeCircle shows % of green AI providers. Click Show Details to see each one.
AAFL Score gaugeLast AI run score out of 10. Green=good, red=needs attention.
Costs chartResponse-time bars for active providers. Fastest provider = shortest bar.
Scout Activity sparkline7-day line showing scout activity. Flat = not running.
ALP Savings barHow many savings you have logged vs a target of 30.
System Status lightsGreen=OK, yellow=uncertain, red=problem. MCC Server / AAFL Engine / Scout.
Refresh CardsForce-reload all home cards from server.
📋 Copy STATUS.mdCopies full STATUS.md text to your clipboard.
📋 Copy HISTORY.mdCopies full HISTORY.md text to your clipboard.
💾 WCCS Tab (Save Session)
What it is: The main save button lives here. Every save backs up STATUS.md and logs what happened.

💾 Save Session NowThe big button. Runs aafl_wccs.py which updates STATUS.md + HISTORY.md. After saving, a flashing reminder tells you to copy and upload STATUS.md to Claude Project Files.
📋 Copy STATUS.md for ClaudeCopies STATUS.md to clipboard. Do this after every save, then paste into Claude.ai Project Files.
Chat Summary textareaPaste your Claude chat notes here before clicking Save. Optional but records context.
Auto-WCCS toggle (header)Saves automatically every N minutes in the background. Set the interval with the number input next to it.
Auto-Save Log pillShows the last 20 saves from wccs_log.md. Date, version, focus, ALP.
History Search pillType anything to search HISTORY.md and ACCA.md. Results highlight your search term.
Session Logs pillBrowse archived session log files. Click one to read its contents.
Rewind + Edit pillPick an old STATUS.md backup from the dropdown, edit its text, then click Restore to make it the live STATUS.md again. Current STATUS.md is backed up first.
Diff Viewer pillPick two backup versions A and B, click Compare. Shows added (green), removed (red), changed (amber) lines.
Sunday Auto-Merge cardRuns merge_sessions.py which combines old session logs.
📋 Kanban · 🔄 AAFL Runs · 🔭 Scout · 💰 Costs
Kanban — Project board from dashboard_data/kanban.json. Refresh to reload.

AAFL Runs — History of completed AI goal runs. Refresh to reload. The Retry Log section loads the last 20 retries.

Scout — Web research runner.
Timed Scout: StartSet a goal + interval + hours limit, click Start. Scout runs repeatedly in background.
Timed Scout: StopWrites a stop flag file. Scout finishes its current run then stops.
Source Library: LoadShows saved URLs. Filter by topic.
Source Library: DiscoverRuns scout in discovery mode to find new relevant URLs.
+ Add SourceManually add a URL + description to the library.

Costs — Cost data from dashboard_data/costs.json. Refresh to reload.
⚙️ AAFL Control Tab
What it is: Run AI goals, set engine settings, manage stuck/failed goals.

Goal inputType the goal for the AI to work on.
Provider dropdownChoose which AI provider to use, or Auto to pick the best free one.
▶ Run NowAdds goal to goal_queue.txt. The AAFL engine picks it up next run.
Cost previewAppears when you type a goal. Shows estimated tokens, cost, and time for the chosen provider.
Suggest ProviderAnalyses your goal text and suggests the best provider. Also auto-selects it in the dropdown.
Run ChainRuns chain_runner.py which processes goals in sequence through multiple providers.
Confidence ThresholdScore (0–10) the AI must beat to accept a result. Below this = retry.
Cost Cap (USD)Max spend per goal before stopping. Free providers ignore this.
Max RetriesHow many times to retry a failing goal before moving to Stuck Inbox.
Stuck InboxGoals that failed too many times. High/Med/Low severity pills shown. Resolve individually or click Bulk Resolve All.
🧠 Memory · ⭐ Promo
Memory — Read-only view of the knowledge database.
Knowledge BankFacts and pages the AI has learnt. Searchable.
Solution LogPast AI solutions with scores and which provider gave them. Searchable.
Source ReputationURLs used as sources, with trust scores based on how reliable they were.

Promo — High-scoring results (≥9.0) auto-queue here for you to approve or reject.
✓ ApproveMarks the result approved. Can Undo within 10 seconds.
✗ RejectMarks the result rejected. Can Undo within 10 seconds.
🛡️ ALP · 💽 Storage · 🔧 Self-Diagnosis
ALP (Accrued Learning Points) — Tracks money and time savings from this project.
Entry inputDescribe the saving or lesson learned (e.g. "Saved 2hrs: used WCCS instead of manual copy").
+ Add EntryAppends the saving as a new row in ALP_Database.md with today's date.

Storage — Monitors disk quota slots from storage_config.json.
Progress barsGreen = under 70%, amber = 70–90%, red = over 90% of quota used.
Weekly ReportShows total allocated, total used, and any warning messages.

Self-Diagnosis — Internal health cockpit.
🔍 Run Full MOTRuns mcc_full_mot.py. Takes ~30 seconds. Shows pass rate and which tests failed.
Module ManagerEnable/disable project modules with checkboxes.
Known Issues + AddLog bugs or problems. Set severity. Mark fixed when done. Delete when closed.
System Info cardsPython version, project path, file count, lines of code, disk usage, last git commit. Auto-loaded on tab open.
File Health tableAll .py files. Click column headers to sort. Import ✓/✗ shows which files import successfully.

📡 How Updates Work (Data Flow)
Saving a session:
1. Paste chat notes into WCCS tab textarea
2. Click Save Session Now
3. Server writes your notes to chat_latest.txt
4. Server runs aafl_wccs.py → updates STATUS.md + HISTORY.md
5. Server copies STATUS.md → archive_dead/STATUS_timestamp.md
6. MCC shows PASS + flashing reminder banner
7. Click "Copy STATUS.md for Claude" button
8. Go to Claude.ai → Project Files → delete old STATUS.md → click + → paste new one

Auto-WCCS:
Toggle ON in the header → server fires every N minutes automatically → same save process, no action needed from you.

What auto-populates:
• Server status dot (every 10s) · Home cards and instruments (every 30s) · Auto-WCCS countdown (1s tick) · ACCA codes (from ACCA.md file) · ALP count · MOT score (after you run it)

What needs manual action:
• Pasting chat summary before save · Clicking Save Session Now · Clicking Copy STATUS.md after save · Uploading STATUS.md to Claude Project Files · Adding new ACCA codes to ACCA.md directly · Adding ALP entries · Running Full MOT

ACCA codes:
Codes are read from ACCA.md as a pipe-table. To add a new code, edit ACCA.md directly and add a row: | CODE | meaning | date |. They appear here on next Refresh.
